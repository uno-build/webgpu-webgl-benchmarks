Benchmark report

WebGPU Engine Bench

The same deterministic scenes measured frame by frame across engines and browsers, on each engine's supported WebGPU and WebGL2 backends. Every supported scene uses identical geometry, lights and camera at 1920×1080 with 4× MSAA and ACES tone mapping; the harness owns the frame loop and times each engine through the same WebGPU instrumentation. Unimplemented or non-equivalent adapter paths are marked N/A.
